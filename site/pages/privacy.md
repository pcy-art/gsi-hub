# 개인정보처리방침

이 문서는 오픈소스 프레임워크가 기본적으로 어떤 데이터를 어떻게 처리하는지 안내하는 템플릿입니다. 실제 서비스 오픈 전 운영 환경에 맞춰 수정하시기 바랍니다.

머리말 요약:

> 본 사이트는 회원가입이나 로그인을 요구하지 않습니다. 사이트의 정상 가동과 피드백 처리에 필수적인 최소한의 정보만 처리하며, 어떠한 개인정보도 제3자에게 판매하지 않습니다.

## 1. 브라우저 로컬 데이터 저장 (서버 미전송)

북마크(저장한 기사), 읽음 처리 기록, 테마 설정(라이트/다크 모드), 최근 검색어(최대 10개), 릴리즈 노트 읽음 상태, 피드백 임시 작성본은 사용자의 브라우저 로컬 스토리지에만 저장됩니다. 이전 화면 복귀 시의 스크롤 위치와 아코디언 펼침 상태는 현재 탭의 세션 스토리지에만 머물며 탭을 닫으면 즉시 소멸합니다. 이 데이터들은 서버로 절대 전송되지 않으며 브라우저 캐시 삭제 시 함께 정리됩니다. 북마크 및 설정은 "보관함" 페이지에서 파일로 내보내기/가져오기가 가능합니다.

## 2. 피드백 접수 데이터

사용자가 피드백 페이지를 통해 직접 입력한 의견, 선택적으로 기재한 이메일 주소, 피드백 제출 당시의 URL 경로 및 첨부 스크린샷은 문의 해결 목적으로 서버에 안전하게 보관됩니다. 비정상적인 반복 호출이나 스팸 공격을 방지하기 위해 IP 주소와 브라우저 정보를 단방향 해시화한 비식별 식별자만 레이트 리밋 용도로 임시 보관됩니다.

## 3. 웹서버 및 인프라 접근 로그

본 소프트웨어는 자체적인 방문자 추적기나 서드파티 트래커를 탑재하지 않습니다. 다만 배포 인프라의 Nginx, Caddy, CDN 등 네트워크 장비 레벨에서 시스템 안정성 유지를 위해 표준 웹 접속 로그(접속 IP, 시간, 요청 URL, User-Agent)가 기록될 수 있습니다.

## 4. 제3자 외부 링크

본 사이트는 외부 기사의 요약 및 원문 출처 링크를 제공합니다. 원문 링크를 클릭하여 외부 웹사이트로 이동하는 경우 해당 사이트의 자체 개인정보처리방침이 적용됩니다.

## 5. 문의 및 정보 열람/삭제

피드백 제출 데이터의 열람, 수정, 파기를 원하시는 경우 상단에 명시된 문의처로 연락해 주시기 바랍니다.
