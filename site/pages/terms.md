머리말 요약:

> 본 사이트는 공개된 정보원을 수집하여 인공지능(AI) 모델을 통해 요약 및 큐레이션을 제공합니다. 원문의 저작권은 각 원작성자 및 출처에 귀속됩니다. 웹페이지, RSS 피드, 공개 API 및 MCP 서비스는 별도의 회원가입 없이 익명으로 자유롭게 이용하실 수 있습니다.

## 1. 콘텐츠 및 저작권

본 사이트에 표시되는 기사 제목, 요약문, 추천 이유는 공개된 원문 자료를 바탕으로 AI 모델이 생성한 결과물입니다. 기계적 가공 특성상 오류가 포함될 수 있으므로 중요한 의사결정이나 정밀한 사실 확인은 반드시 원문을 참조하시기 바랍니다. 모든 원문의 저작권은 각 출처에 있습니다. 사이트 내에서는 출처 측이 명시적으로 허용한 경우에만 전문(Full-text)을 제공하며, 그 외에는 요약문과 원문 링크만 노출합니다.

## 2. 출처(원작성자)의 정정 및 게시 중단 요청

원문 출처의 권리자로서 내용 정정, 노출 중단 또는 표시 방식 변경을 희망하시는 경우, 문의처 또는 피드백 페이지를 통해 요청해 주시면 확인 후 신속하게 처리해 드리겠습니다.

## 3. 사이트 데이터 활용 범위

개인적인 열람 및 조직 내부 업무 목적의 자유로운 이용을 환영합니다. 단, 본 사이트의 가공 데이터를 활용한 상업적 상품 출시, 대규모 무단 재배포 및 데이터베이스 구축 등은 사전 협의가 필요합니다.

## 4. API 및 호출 빈도 제한

RSS, 공개 REST API 및 MCP는 비인증 읽기 전용으로 제공됩니다. 응답 헤더의 캐시 만료 시간(`Cache-Control`)을 준수해 주시기 바라며, HTTP 429(Too Many Requests) 수신 시 `Retry-After` 헤더의 대기 시간을 준수하고 동시 다발적인 무작위 재시도를 자제해 주세요.

## 5. 면책 조항

본 서비스는 "있는 그대로(AS-IS)" 제공되며, 수집된 정보의 완전성, 정확성 및 서비스의 무중단 지속성을 보증하지 않습니다.
