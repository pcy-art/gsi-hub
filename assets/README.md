# 정적 에셋 (Assets)

사이트에서 직접 제공하는 정적 파일들이 위치합니다. 동봉된 [NOTICE](../NOTICE) 및 [LICENSE](../LICENSE) 규정을 함께 준수해야 합니다.

| 디렉터리 | 내용 | 비고 |
|---|---|---|
| `og-fonts/` | Noto Sans SC / Noto Sans KR 400·700 (SIL OFL 1.1) | 서버 사이드 공유 이미지(OG Image) 및 포스터 생성 전용. 웹 화면은 시스템 폰트를 사용하므로 클라이언트 폰트 다운로드가 발생하지 않습니다. |

사이트 고유의 아이콘, 로고, 리포트 헤더 이미지는 `site/brand/`에 위치하며, 산업군 변경 시 해당 폴더의 파일들을 교체합니다.
