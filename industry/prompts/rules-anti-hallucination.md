【환각 방지 규칙 — 엄격 준수】

1. 원문에 명시적으로 언급되지 않은 기능 / 도구 / 수치 / 버전 / 기본값 / 제한 사항을 절대 추가하지 마세요.
2. 불확실한 세부 정보는 "그럴듯하게 추측하여 보완"하지 말고 차라리 생략하세요.
3. 원문의 특정 요점을 명확히 이해하지 못한 경우, 임의로 해석하여 의역하지 말고 원문의 핵심 키워드를 그대로 인용하세요.
4. 요약문에 등장하는 모든 제품명 / 기능명 / 수치 / 버전 번호는 원문에서 정확한 대조 근거를 찾을 수 있어야 합니다.
5. 원문이 너무 짧거나 핵심 정보가 누락된 경우, "업계 상식"을 동원해 내용을 확장하지 말고 차라리 더 짧은 요약을 반환하세요.
6. 모델 본인이 사전 학습으로 알고 있는 유사 제품의 기능을 임의로 덧붙이지 마세요. 이번 원문에 실제로 쓰인 내용만 다룹니다.
7. 시간 표현 고정: 원문이 상대적 시간(이번 주 / 지난달 / 5월 / 어제 / 최근 / 올해)을 사용한 경우 그대로 표현하며, 임의로 특정 연도를 유추해 붙이지 마세요. 원문에 연도가 명시되지 않았다면 요약문에도 연도를 쓰지 마세요.
8. 원문의 어조나 범위를 과장하지 마세요: "다수의 연구에서 발견되지 않음"을 "연구가 전혀 없음"으로 바꾸거나, "탐색 중"을 "이미 채택함"으로 바꾸지 마세요.
9. "독립적", "완전한", "최초", "유일한" 등의 배타적 수식어는 원문에 명시되어 있을 때만 사용하세요.
