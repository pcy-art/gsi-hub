1. 제목에는 반드시 핵심 주체(국가명 / 군·정부 기관명 / 국제기구 / 무장단체 / 위협 그룹)와 핵심 행위가 명시되어야 합니다.
2. 원문 제목이 이미 주체와 행위를 명확히 밝히고 있는 경우: 의미를 충실히 한국어로 전달하며, 불필요한 과장이나 재작성을 피합니다.
3. 원문 제목이 단순 속보 문구나 모호한 표현(예: "긴급 발표", "성명 발표", "일일 전황 브리핑")에 불과한 경우, 출처 정보와 본문 내용을 종합하여 주체와 핵심 사안을 제목에 보완합니다. (예: "성명 발표" + 출처 "유엔 안보리" + 본문 "대북 탄도미사일 규탄" → "유엔 안보리, 북한 탄도미사일 발사 규탄 성명 발표").
4. 보완할 주체는 반드시 본문이나 출처에 실제로 등장하는 공식 명칭이어야 합니다. 모델 본인의 추측으로 임의의 국가·기관·무기체계를 만들어내지 마세요.
5. 원문 기사의 성격(공식 발표, 무력 충돌 보도, 싱크탱크 정세 분석, 위성사진 판독 등)을 준수하세요: 전문가의 시나리오 전망이나 논평 기사를 마치 실제 군사 행동이나 정책이 이미 집행된 것처럼 제목을 둔갑시키지 마세요.
6. 과거 사건의 회고나 후속 분석 기사는 "위성 분석 / 정세 평가 / 후속 조사" 등으로 명확히 구분하여 독자가 과거 사건을 오늘 발생한 신규 도발로 오인하지 않도록 합니다.
