【안보·외교·군사 도메인 용어 표기 규칙 — 본 플랫폼은 글로벌 안보 인텔리전스 전문 포털입니다】

1. 군사·안보·외교 전문 용어는 국내 국방·외교 표준 용어로 정확히 표기합니다:
   - ICBM = 대륙간탄도미사일(ICBM), IRBM = 중거리탄도미사일(IRBM), SRBM = 단거리탄도미사일(SRBM), SLBM = 잠수함발사탄도미사일(SLBM)
   - MIRV = 다탄두 각개목표 설정 재돌입 비행체(MIRV), MARV = 기동형 재돌입체
   - TEL = 이동식 발사대(TEL)
   - NLL = 북방한계선(NLL), DMZ = 비무장지대(DMZ), JSA = 공동경비구역(JSA), MDL = 군사분계선(MDL)
   - ADIZ / KADIZ = 방공식별구역(ADIZ / KADIZ), EEZ = 배타적 경제수역(EEZ), SLOC = 해상교통로(SLOC)
   - STS (Ship-to-Ship) = 해상 불법 환적(STS)
   - NCG = 한미 핵협의그룹(NCG), Extended Deterrence = 확장억제
   - OPCON = 전시작전통제권(전작권)
   - EW = 전자전(EW), ISR = 정보·감시·정찰(ISR), C4ISR = 지휘통제·통신·컴퓨터·정보·감시·정찰
   - APT = 지능형 지속 위협(APT) 해킹 조직

2. 국제기구·동맹·주요 기관 및 무기체계 명칭 표기 원칙:
   - 국제기구/협의체: UN / 유엔 안보리(UNSC) / IAEA / NATO / QUAD / AUKUS / EU / G7 / OFAC(미 재무부 해외자산통제국) / MSMT(다국적제재모니터링팀)
   - 주요 당국: 합참(JCS) / 국방부(MND) / 주한미군(USFK) / 미 국방부(DoD·펜타곤) / 미 인도태평양사령부(INDOPACOM) / 미 중부사령부(CENTCOM) / 일본 방위성 / 중국 인민해방군(PLA) / 러시아 국방부 / 이란 이슬람혁명수비대(IRGC)
   - 북한 매체·기관: 조선중앙통신(KCNA) / 노동신문 / 국방성 / 미사일총국
   - 사이버 위협 그룹: 라자루스(Lazarus) / 김수키(Kimsuky) / 안다리엘(Andariel) / APT38 / APT28 / APT29 / 볼트 타이푼(Volt Typhoon)
   - 무기체계 제식명(예: 화성-17형, 화성-18형, 극초음속 미사일, 사헤드-136, 패트리엇, 사드 THAAD, 이지스, F-35, B-52H, 오하이오급 SSBN 등)은 원문 제식 번호와 명칭을 정확히 유지합니다.

3. 수치·제원·좌표·일시·금액은 **임의 변형 없이 원형 유지**:
   - 사거리, 비행 고도, 마하(Mach) 속도, 발사 시각, 위경도 좌표, 선박 IMO 번호, 제재 금액($, 유로, 원), 사상자/피해 수치는 원문의 숫자와 단위를 그대로 보존합니다.
   - CVE 취약점 번호(`CVE-2025-...`), 해시값, 도메인, 명령어는 번역하지 않고 원형을 유지합니다.
